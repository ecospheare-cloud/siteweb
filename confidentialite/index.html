Confidentialité

Un site sans traceur publicitaire

Cette version du site n’utilise ni outil de mesure d’audience, ni cookie publicitaire, ni stockage local des informations du formulaire. Les images du portfolio sont hébergées avec le site. Les polices sont chargées depuis Google Fonts et le fond vidéo depuis Amazon CloudFront : ces chargements transmettent notamment votre adresse IP aux serveurs concernés. Le site est hébergé sur GitHub Pages.

Le formulaire de contact

Les informations saisies restent dans votre navigateur. Le bouton prépare un e-mail destiné à contact@ecospheare.com dans votre application de messagerie. Vous décidez de l’envoyer. Le téléchargement du brief crée un fichier sur votre appareil.

Une fois l’e-mail envoyé

Le message est traité par les services de messagerie utilisés par vous et par ECOSPHEARE, pour répondre à votre demande. Pour toute question concernant votre message, écrivez à Contact.

Vos demandes

Pour une question sur vos données ou une demande d’accès, de rectification ou de suppression, contactez Sacha Zacharewicz à contact@ecospheare.com.
